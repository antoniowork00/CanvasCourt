## About

**CanvasCourt** is a frontend project that combines **basketball, street culture, urban art and modern web design** into a single interactive experience.

The idea is simple:

> **Every court has a story.**

The platform allows users to discover outdoor basketball courts, explore their surroundings and contribute by adding new playgrounds.

## Design

CanvasCourt follows a visual identity inspired by **street basketball, sports interfaces and urban art**.

<div align="center">

|     Element    | Choice         |
| :------------: | :------------- |
|   Background   | `#121212`      |
|     Surface    | `#2A2A2A`      |
|     Primary    | `#FE5314`      |
|      Text      | `#FFFFFF`      |
| Secondary Text | `#B3B3B3`      |
|  Display Font  | **Bebas Neue** |
|    Body Font   | **Inter**      |
|    Mono Font   | **Space Mono** |

</div>

The design focuses on **strong contrast, clear hierarchy, responsive layouts and subtle interactions**.
